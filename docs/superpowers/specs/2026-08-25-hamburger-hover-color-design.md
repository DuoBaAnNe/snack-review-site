# 三横杠菜单悬停颜色设计

## 目标

让首页和每个零食详情页左上角的三横杠菜单按钮，在鼠标悬停时显示与“七零十”Logo 相同的橙色反馈。

## 交互设计

- 默认状态继续使用现有深灰色图标。
- 鼠标移入按钮后，三条横线变为 `orange-500`。
- 保留现有的淡白色悬停背景和颜色渐变动画。
- 鼠标移开后恢复默认深灰色。
- 不改变按钮的位置、尺寸、圆角、菜单开关行为或键盘操作。

## 修改范围

- `src/components/HomePageContent.tsx`：首页三横杠菜单按钮。
- `src/components/SnackDetailNavigation.tsx`：所有零食详情页共用的三横杠菜单按钮。

两处按钮直接增加 Tailwind 类 `hover:text-orange-500`。不抽取新组件，不增加全局 CSS，也不修改 Logo 样式。

## 验证

- 自动检查两处菜单按钮都包含橙色悬停类。
- 运行相关导航测试、专项 ESLint 和生产构建。
- 在本地浏览器分别检查首页与零食详情页：默认深灰色，悬停变橙色，移开恢复，点击仍可正常打开菜单。

## 部署

先在本地完成验证。未经用户再次确认，不部署线上。
