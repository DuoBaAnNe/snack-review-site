# 地图省份卡片与顶部导航栏层级设计

## 目标

省份零食卡片继续固定在地图内的点击位置，并随地图一起滚动；卡片进入顶部导航栏区域时必须从导航栏下面经过并被导航栏遮住，不能覆盖网站标题、倒计时或登录按钮。

## 当前问题与根因

顶部导航栏使用 `z-50`。省份卡片使用 `z-[9999]`，且没有被限制在一个低于导航栏的独立堆叠上下文中。页面向上滚动时，卡片的几何位置虽然正确地跟随地图变化，但其层级高于导航栏，所以会绘制在导航栏上方。

## 方案

在地图的相对定位容器上建立独立堆叠上下文，并将省份卡片层级设为 `z-30`：

- 地图画布保留默认层级。
- 省份卡片使用 `z-30`，继续显示在地图画布上方。
- 顶部导航栏继续使用全站既有的 `z-50`，因此始终显示在卡片上方。
- 不改变卡片的绝对定位坐标、点击固定逻辑、滚动逻辑或关闭逻辑。
- 不使用 `overflow-hidden`，避免卡片靠近地图边缘时被地图容器错误裁剪。

## 层级关系

从低到高：

1. 地图画布。
2. 省份零食卡片（`z-30`）。
3. 顶部导航栏（`z-50`）。

## 验证

- 修改前在浏览器中确认卡片计算层级为 `9999`、导航栏为 `50`，能够复现覆盖问题。
- 修改后确认卡片计算层级低于导航栏，同时仍高于地图画布。
- 点击有零食的省份并向上滚动，确认卡片与地图同步移动，在进入导航栏区域后被导航栏遮住。
- 运行地图定位测试、其他回归测试和生产构建。

## 不在本次范围

- 不改变导航栏高度、透明度或固定方式。
- 不让卡片吸附在导航栏下方。
- 不改变省份卡片内容或视觉样式。
- 先在本地验证；未经新的明确确认不部署线上。
