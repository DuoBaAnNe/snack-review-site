# 食品资讯悬浮收起按钮设计

## 目标

首页“食品资讯”展示全部资讯后，访客在资讯区的任意滚动位置都能立即收起列表，无需回到列表末尾。

## 范围

- 仅修改首页 `src/components/NewsList.tsx` 的“查看更多资讯”交互。
- 不涉及对战、小程序、数据库、接口或部署。

## 交互

1. 默认仅显示前 18 条匹配资讯，并在底部提供“查看更多资讯”。
2. 点击后展示全部匹配资讯，同时显示一个粘附在资讯区右侧的“收起资讯”按钮。
3. 桌面端按钮位于列表右侧中部；窄屏时位于视口右下角，避免遮挡卡片正文。
4. 点击该按钮后恢复前 18 条，并使用平滑滚动让食品资讯标题回到可见位置。
5. 筛选资讯类别后，按钮继续作用于当前筛选结果；当前结果不超过 18 条时不显示展开/收起控件。

## 实现与验证

`NewsList` 继续以 `showAll` 管理展开状态。新增一个只在 `showAll && hasMore` 时渲染的收起按钮；其事件将状态设为 `false`，随后将最近的资讯区容器滚动到视口起始位置。为避免页面结构耦合，列表组件自身为控制区提供 ref 和可访问标签。

通过 `npm run lint`、`npm run build` 验证 TypeScript 与生产构建；本地启动后手动验证展开、任意位置收起、筛选后收起和窄屏布局。
